## Tips
1.在MacOS首次安装打开之后，通常需要用户在Mac的 "设置-安全与隐私" 里面允许本应用运行，否则系统可能会提示本应用文件破损，不能打开运行之类的信息。

2.通常情况是使用默认的设定即可，如需要改动设定，请阅读文档信息之后再正确设定。

3.打开应用之后或者切换模型之后，如果立刻向AI提问，此时模型可能还未加载完成，界面回复的文本可能是 空白 。这是正常的，应用加载模型需要一定时间（不同电脑硬件加载不同模型需要的时间各有不同），请在打开软件之后稍等一下（5s -> 60s）再向AI发送问题。

4.安装后首次打开本应用耗时要长一些（30s --> 70s），是属于正常的现象。后续打开应该在10s之内就可以打开了。
